## 1. ภาพรวมของระบบ
ระบบรายงานเงินปันผลเฉลี่ยคืน พัฒนาขึ้นเพื่อให้บริการทั้ง **เจ้าหน้าที่สหกรณ์** และ **สมาชิกสหกรณ์** โดยแบ่งออกเป็น 2 ระบบย่อยที่ทำงานร่วมกันอย่างเป็นเอกภาพ:

1. **ระบบเจ้าหน้าที่และผู้ดูแลระบบ (Admin Dashboard)**:
   * **รองรับข้อมูลหลายปีงบประมาณ (Multi-Year)**: สลับดูและจัดการข้อมูลได้ทุกปีงบประมาณ (เช่น 2568, 2569, 2570)
   * **อ่านข้อมูลจาก Master Excel (`data-mast.xlsx`)**: จัดการข้อมูลง่ายผ่าน Excel แยกตาม Sheet แต่ละปี
   * **ค้นหาและพิมพ์รายงานครบครัน**: พิมพ์รายหน่วยงาน, ค้นหารายบุคคล, กรองสถานะ และเลือกติ๊กพิมพ์เฉพาะคนที่ต้องการ
   * **แก้ไขข้อความใน PDF ผ่านหน้าเว็บ**: เปลี่ยนอัตรา %, วันที่ยอดคงเหลือ, กำหนดการประชุมใหญ่ ได้โดยไม่ต้องแก้โค้ด

2. **ระบบตรวจสอบเงินปันผลสำหรับสมาชิก (Member Portal)**:
   * **เข้าสู่ระบบอย่างปลอดภัย (Self-Service)**: สมาชิกเข้าสู่ระบบด้วย **รหัสสมาชิก** + **เลขบัตรประชาชน 4 หลักท้าย**
   * **ล็อกปีงบประมาณปัจจุบันอัตโนมัติ**: แสดงข้อมูลงวดปีปัจจุบันทันทีโดยที่สมาชิกไม่ต้องเลือกปีเอง
   * **หน้าจอสรุปยอดเงินส่วนบุคคล**: แสดงยอดเงินปันผล, เฉลี่ยคืน, รายการหัก, และยอดรับสุทธิเด่นชัด รองรับทั้งบนมือถือและคอมพิวเตอร์
   * **รักษาความลับข้อมูล (Data Privacy)**: ตรวจสอบสิทธิ์ที่ Server และส่งเฉพาะข้อมูลของสมาชิกท่านนั้นคนเดียว ไม่มีการส่งข้อมูลเพื่อนสมาชิกคนอื่นไปที่เบราว์เซอร์
   * **ดาวน์โหลด PDF ฉบับทางการ**: สมาชิกสามารถกดดาวน์โหลดใบรายงานเงินปันผลขนาด A4 ของตนเองได้ทันที

## 5. ขั้นตอนการอัปเดตข้อมูล (Data Update)

เมื่อมีการแก้ไขหรือเพิ่มข้อมูลใน `data-mast.xlsx` ให้ดำเนินการอัปเดตข้อมูลเข้าสู่ระบบดังนี้:

1. บันทึกและปิดไฟล์ `data-mast.xlsx`
2. เปิด Command Prompt หรือ PowerShell แล้วรันคำสั่ง:
   ```powershell
   python convert_data.py
   ```
3. โปรแกรมจะอ่าน Sheet ทั้งหมดใน Excel และสร้างไฟล์ใน `ds/` ให้อัตโนมัติ พร้อมส่งสัญญาณรีโหลดไปยังระบบเว็บทันที

## 6. การเริ่มต้นใช้งานระบบ (How to Run)

สามารถเลือกรันระบบได้ตามวัตถุประสงค์การใช้งาน:

### 💼 6.1 การรันระบบเจ้าหน้าที่ (Admin Dashboard)

  ```powershell
  node member_server.js
  ```
  จากนั้นเปิดเบราว์เซอร์ไปที่: **`http://localhost:8088`**

## 8. ระบบสมาชิก (Member Portal) - พอร์ต 8088

ระบบออกแบบมาเพื่อให้สมาชิกสหกรณ์สามารถตรวจสอบยอดเงินปันผล-เฉลี่ยคืนของตนเองได้อย่างสะดวก รวดเร็ว และปลอดภัย

### 8.1 การเข้าสู่ระบบของสมาชิก (Login)
1. เปิดเบราว์เซอร์ไปที่ `http://localhost:8088`
2. ระบบจะแสดง **ปีงบประมาณปัจจุบัน** ให้ทราบโดยอัตโนมัติ (เช่น `📅 ปีงบประมาณ 2568 (2025)`)
3. กรอกข้อมูลยืนยันตัวตน:
   * **รหัสสมาชิก**: กรอกเลขสมาชิกของตนเอง (เช่น `22` หรือ `00022` ระบบจะเติม 0 ข้างหน้าให้อัตโนมัติ)
   * **เลขบัตรประชาชน (4 หลักสุดท้าย)**: ระบุตัวเลข 4 หลักสุดท้ายของบัตรประชาชน 13 หลัก (มีปุ่มเปิด/ปิดดูตัวเลขได้)
4. กดปุ่ม **"เข้าสู่ระบบ (Login)"**

### 8.2 หน้าจอ Dashboard สมาชิก
เมื่อเข้าสู่ระบบสำเร็จ จะพบข้อมูลส่วนบุคคล:
* **การ์ดสรุปยอดรับสุทธิ (Hero Net Payout)**: แสดงยอดรับสุทธิหลังหักรายการต่างๆ ตัวเลขขนาดใหญ่ ชัดเจน พร้อมช่องทางการรับเงิน (โอนเข้าบัญชี หรือ รับเงินสด)
* **การ์ดสรุป 4 ยอดหลัก**: เงินปันผล (พร้อมระบุอัตรา %), เงินเฉลี่ยคืน (พร้อมระบุอัตรา %), รวมเงินได้, และรวมรายการหัก
* **ตารางยอดคงเหลือ ณ สิ้นปี**: ทุนเรือนหุ้นสะสม, เงินกู้สามัญ, เงินกู้พิเศษ 1-4, ภาระค้ำประกัน
* **ตารางรายการหักเงิน**: ประกันชีวิต, ชำระหนี้, ฌาปนกิจต่างๆ
* **ปุ่มดาวน์โหลดรายงาน**: กดปุ่ม **"⬇️ ดาวน์โหลด / พิมพ์เป็น PDF"** เพื่อเปิดเอกสารฉบับทางการ

### 8.3 การกำหนดปีงบประมาณปัจจุบันของระบบสมาชิก
สามารถเปลี่ยนปีงบประมาณที่เปิดให้สมาชิกเข้าดูได้ที่ **บรรทัดที่ 15** ของไฟล์ `member_server.js`:
```javascript
// กำหนดปีงบประมาณปัจจุบัน (Current Fiscal Year)
// สามารถเปลี่ยนปีตรงนี้ได้เลย เช่น '2025' (ปี 2568) หรือ '2026' (ปี 2569)
const ACTIVE_YEAR = process.env.CURRENT_YEAR || '2025';
```
*(เมื่อสหกรณ์ปิดงวดบัญชีปีใหม่ เพียงเปลี่ยนเป็น `'2026'` ระบบจะสลับไปดึงข้อมูลปี 2569 ให้อัตโนมัติทันที)*

## 10. การแก้ไขข้อความและแม่แบบรายงาน PDF (Config Customization)

## 11. ขั้นตอนการเพิ่มปีข้อมูลใหม่ในอนาคต

4. บันทึกไฟล์ และรันคำสั่ง:
   ```powershell
   python convert_data.py
   ```
5. ระบบจะดำเนินการอัตโนมัติ:
   * สร้างไฟล์ `ds/data2028.json` และ `ds/data2028.xlsx` ในโฟลเดอร์ `ds/`

   * ส่งสัญญาณรีโหลดข้อมูลไปยัง `server.js` เพื่ออัปเดตข้อมูลปีใหม่ทันทีโดยไม่ต้อง Restart Server
