## 1. ภาพรวมของระบบ
ระบบรายงานเงินปันผลเฉลี่ยคืน พัฒนาขึ้นเพื่อทดแทนระบบเดิม โดยเพิ่มความสามารถ:
* **รองรับข้อมูลหลายปีงบประมาณ (Multi-Year)**: สลับดูข้อมูลระหว่างปีต่างๆ ได้ทันที (เช่น ปี 2569 / ปี 2568)
* **อ่านข้อมูลจาก Master Excel (`data-mast.xlsx`)**: จัดการข้อมูลผ่าน Excel ตาม Sheet แต่ละปีได้อย่างสะดวก
* **แก้ไขรายละเอียดใน PDF ได้ง่าย**: ไม่มีการ Hardcode ข้อมูล สามารถเปลี่ยน ปีงบประมาณ, อัตราปันผล-เฉลี่ยคืน, กำหนดการประชุมใหญ่, และผู้ลงนามได้ผ่านหน้าเว็บโดยไม่ต้องแก้โค้ดโปรแกรม
* **ตัวเลือกค้นหาและพิมพ์รายงานครบครัน**: พิมพ์รายหน่วยงาน, ค้นหารายบุคคล, กำหนดช่วงรหัส, กรองสถานะ และเลือกติ๊กพิมพ์เฉพาะคนที่ต้องการ
* **การพิมพ์ A4 มาตรฐาน 100%**: รองรับการสั่งพิมพ์ผ่านเบราว์เซอร์หรือบันทึกเป็นไฟล์ PDF คมชัดด้วยฟอนต์ TH Sarabun New

## 5. ขั้นตอนการอัปเดตข้อมูล (Data Update)

เมื่อมีการแก้ไขหรือเพิ่มข้อมูลใน `data-mast.xlsx` ให้ดำเนินการอัปเดตข้อมูลเข้าสู่ระบบดังนี้:

1. บันทึกและปิดไฟล์ `data-mast.xlsx` (ซึ่งอยู่ในโฟลเดอร์ `new_system/`)
2. เปิด PowerShell หรือ Command Prompt เข้าไปที่โฟลเดอร์ `new_system/` แล้วรันคำสั่ง:
   ```powershell
   py convert_data.py
   ```
3. สคริปต์จะประมวลผลและแสดงรายงาน:
   ```text
   Using primary data-mast.xlsx in same directory: .../new_system/data-mast.xlsx
   Loading workbook: ...
   Available Sheets in data-mast.xlsx: ['data2026', 'data2027']

   Processing Sheet: 'data2026' -> Year: '2026'
   [OK] Successfully exported ... records to .../ds/data2026.json
   [OK] Successfully exported Excel to .../ds/data2026.xlsx
   ...
   Sending reload notification to server (HTTP GET /api/reload)...
   [OK] Server reloaded successfully
   ```
4. ข้อมูลในระบบเว็บไซต์จะอัปเดตพร้อมใช้งานทันทีโดยไม่ต้อง Restart Server

## 6. การเริ่มต้นใช้งานระบบ (How to Run)

### วิธีที่ 1: ดับเบิลคลิกไฟล์ Batch (ง่ายที่สุด)
1. เข้าไปที่โฟลเดอร์ `new_system`

```powershell
cd new_system
node server.js
```

## 8. การพิมพ์รายงาน PDF ขนาด A4

ระบบรองรับการพิมพ์ได้ 3 รูปแบบ:
1. **พิมพ์รายคน**: คลิกปุ่ม **"🖨️ พิมพ์"** ที่แถวด้านหลังชื่อสมาชิกคนนั้น
2. **พิมพ์เฉพาะคนที่เลือก**: ติ๊กถูกที่ช่องสี่เหลี่ยมหน้าชื่อสมาชิกหลายๆ คน แล้วคลิกปุ่ม **"🖨️ พิมพ์ที่เลือก (X)"** ด้านบน
3. **พิมพ์ทั้งหน่วยงาน**: เลือกหน่วยงานที่ต้องการ แล้วคลิกปุ่ม **"📑 พิมพ์ทั้งหน่วยนี้"**

### การตั้งค่าหน้าพิมพ์ในเบราว์เซอร์ (Print Settings)
เมื่อหน้าต่างพิมพ์ A4 ปรากฏขึ้น ให้กดปุ่ม **"พิมพ์เอกสาร / บันทึกเป็น PDF"** หรือกด `Ctrl + P` และตั้งค่าดังนี้:
* **Destination (เครื่องพิมพ์ปลายทาง)**: เลือกเป็นเครื่องพิมพ์ หรือเลือก **Save as PDF** เพื่อบันทึกเป็นไฟล์ PDF
* **Paper size (ขนาดกระดาษ)**: **A4**
* **Layout (การวางแนว)**: **Portrait (แนวตั้ง)**
* **Margins (ระยะขอบ)**: **None (ไม่มี)** หรือ **Default**
* **Options**: ติ๊กเครื่องหมายถูกที่ **Background graphics (กราฟิกพื้นหลัง)** เพื่อให้รูปภาพลายเซ็นและเส้นตารางแสดงครบถ้วน

## 9. การแก้ไขข้อความและแม่แบบรายงาน PDF (Config Customization)

หากต้องการเปลี่ยนปีงบประมาณ, วันที่ยอดคงเหลือ, อัตราเปอร์เซ็นต์, กำหนดการประชุมใหญ่ หรือผู้ลงนาม สามารถทำได้ 2 วิธี:

### วิธีที่ 1: แก้ไขผ่านหน้าเว็บ (แนะนำ)
1. คลิกที่ปุ่ม **"⚙️ ตั้งค่าเอกสาร / Template"** บนแถบเมนู
2. หน้าต่างตั้งค่าจะแสดงข้อมูลของปีงบประมาณที่เลือกอยู่ปัจจุบัน:
   * ประจำปีงบประมาณ (เช่น `2569`)
   * ยอดคงเหลือ ณ วันที่ (เช่น `ณ 30 ก.ย.69`)
   * อัตราเงินปันผล (%) / อัตราเงินเฉลี่ยคืน (%)
   * วันที่และเวลาประชุมใหญ่สามัญประจำปี
   * เวลาเริ่มประชุม / เวลาเริ่มลงคะแนนเลือกตั้ง
   * ยศ, ชื่อ-สกุล, ตำแหน่ง และรูปลายมือชื่อผู้จัดการ
3. กดปุ่ม **"💾 บันทึกการตั้งค่า"** ข้อความทั้งหมดจะอัปเดตลงในรายงาน PDF ทันที

## 10. ขั้นตอนการเพิ่มปีข้อมูลใหม่ในอนาคต

เมื่อถึงรอบปีงบประมาณถัดไป (เช่น ปี 2028 / 2571) ให้ดำเนินการตามขั้นตอนนี้:

1. เปิดไฟล์ `data-mast.xlsx`
2. สร้าง Sheet ใหม่ขึ้นมา แล้วตั้งชื่อ Sheet ว่า **`data2028`** (หรือ `2028`)
3. วางข้อมูลสมาชิกตามรูปแบบ 34 คอลัมน์ (ตามตารางในข้อ 4)
4. บันทึกไฟล์ และรันคำสั่ง:
   ```powershell
   py new_system\convert_data.py
   ```
5. ระบบจะดำเนินการอัตโนมัติ:
   * สร้างไฟล์ `ds/data2028.json` และ `ds/data2028.xlsx` ในโฟลเดอร์ `ds/`
   * สร้างค่าตั้งค่าเริ่มต้นของปี 2028 ลงใน `config.json` ให้อัตโนมัติ
   * ส่งสัญญาณ HTTP GET ไปยัง `/api/reload` เพื่อให้ `server.js` เรียก `initData()` อัปเดตข้อมูลปีใหม่ทันทีโดยไม่ต้อง Restart Server
   * เพิ่มตัวเลือก **"ปี 2571 (2028)"** ลงใน Dropdown บนหน้าเว็บให้อัตโนมัติ
